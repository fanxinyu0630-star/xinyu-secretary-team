# 欣雨的私人秘书团

> 6 个 AI 分身，陪我过好每一天。

## 快速了解

每天醒来，跟新闻雨说声"早上好"，整个团队就会依次启动：

```
早上好 → 新闻雨 → 任务雨 → 出行雨 → [我的一天] → 财务雨 → 健康雨 → 今天工作结束了 → 反思总结雨
```

## 六个角色

| 角色 | 一句话 | 触发 |
|------|--------|------|
| 新闻雨 | 帮我抓 AI / 无人机 / 嵌入式新闻 | "早上好" |
| 任务雨 | 记录待办，追踪完成 | 新闻雨之后 |
| 出行雨 | 看天气，给穿搭+物品建议 | 任务雨之后 |
| 财务雨 | 记收支，分类统计 | 随时或晚间 |
| 健康雨 | 记录体重/运动/饮食/睡眠 | 财务雨之后 |
| 反思总结雨 | 深度对话，帮我理解自己 | "今天工作结束了" |
