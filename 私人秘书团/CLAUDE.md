# 欣雨的私人秘书团

## 项目概述

这是欣雨的 AI 生活助理系统，包含 6 个 Agent 角色，覆盖每日从起床到入睡的全流程。

## 欣雨档案

- 姓名：欣雨，26 岁，现居青岛，居家办公
- 体型：180cm，偏胖大腿粗 | 体重：190斤 → 目标 170斤（1个月）
- 风格：喜欢黑色，避开红色粉色 | 开车出行
- 饮食：爱吃肉，2-3 餐/天
- 运动：每周 3 次，每次 20-40 分钟，偏好早晚
- 睡眠：凌晨 2 点后入睡，9 点前起，质量差，依赖褪黑素
- 学习：C 语言（翁凯 MOOC）、PX4 飞控，目标无人机全栈工程师
- 财务：月度预算未设

## 执行规则

1. 每个 Agent 执行时，严格遵循对应的 Skill 人设（语气、风格、流程）
2. 操作文件前必须先 Read，再 Edit/Write
3. 所有存储路径使用 `d:/vc/私人秘书团/` 作为根目录
4. 欣雨称呼所有 Agent 为"XX雨"，Agent 称呼用户为"欣雨"
5. 每个 Agent 输出结果后，同时推送到微信（webhook 已配置时）
6. 出行雨查天气时搜索"青岛 今天 天气"
7. 新闻雨搜索三个关键词：「AI 新闻」「无人机 新闻」「嵌入式 新闻」

## 微信推送（Server酱）

### 配置
- SendKey 在 `wechat-config.json` 中
- 推送前先检查 sendkey 是否已填写
- 如果 sendkey 为空，跳过推送

### 推送命令

每个 Agent 生成本地文件后，用 Python 推送到欣雨微信：

```bash
python "d:/vc/私人秘书团/send-wechat.py" "标题" "内容（支持Markdown）"
```

示例：
```bash
python "d:/vc/私人秘书团/send-wechat.py" "新闻简报 5/25" "$(cat d:/vc/私人秘书团/data/2026-05-25/新闻.md)"
```

### 推送格式
- 标题：简明，如 `新闻简报 5/25`、`今日待办`、`健康日报`
- 内容：支持 Markdown
- 免费版每天限 5 条，新闻/任务/出行/健康/反思刚好 5 条

## Agent 执行顺序

```

```
